# Put your clips here

Make one folder per video, e.g. `contents/MY VLOG/`. Straight from your phone is fine (4K, HDR, portrait or landscape).

Name the clips; the names are instructions:

| Name | Meaning |
|---|---|
| `START` | Plays first |
| `2`, `3`, `4` … | Story order |
| `6 (PRODUCT DEMO)` | Text in brackets says what the clip is |
| `B-ROLL …` | Extra shots to use where they fit |
| `ENDING` | Plays last, before the end card |

Then tell Claude Code: "Edit `contents/MY VLOG` for TikTok. It's about ___."
